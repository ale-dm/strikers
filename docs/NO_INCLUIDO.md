# Qué no está en este repositorio

Este repositorio es público. Por eso no incluye:

- **ISOs del juego** (Japón, Traducción, etc.): hace falta tu copia legal.
- **Archivos extraídos del juego** (`dat.bin`, `grp.bin`, `scn.bin`, `main.dol`, etc.).
- **Parches de traducción** de TraduSquare / Ina11 Translations: su página prohíbe redistribuirlos fuera de su web oficial.
- **Paquete del mod Infinity** (DexterZSP): texturas, modelos, audio y datos de Level-5 y del autor.
- **Partidas guardadas** (`xtreme2.sav`, `xtreme3.sav`, etc.).
- **Configuración personal de Dolphin** y rutas de tu equipo.

Dónde conseguir cada cosa, de forma pública:

- Código fuente de Xtreme: https://github.com/obluda3/strikers2013-xtreme
- Documentación de Xtreme: https://obluda3.github.io/strikers
- Editor de jugadores: https://github.com/obluda3/Strikers2013Editor
- Herramientas de traducción y ShadeLz: https://github.com/obluda3/Strikers2013-Tools
- Traducción castellano (página oficial): https://tradusquare.es/proyectos/inazuma-eleven-go-strikers-2013/
- Mod Infinity (página oficial del autor): https://inazuma-eleven.fr/mods/mod.html?slug=inazuma-eleven-strikers-infinity
